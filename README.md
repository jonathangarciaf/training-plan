# Training Plan

Personal gym training checklist — a mobile-first web app for tracking workouts.

**Live app:** https://jonathangarciaf.github.io/training-plan/

## What it does

- Two workout days (Day A / Day B) you can switch between
- Per-exercise checklist with a progress bar
- Training calendar to track which days you trained
- Exercise reference images
- Progress is saved in the browser (`localStorage`), so it persists between visits

## Running locally

No build step, no dependencies. Open `gym.html` directly in a browser.

## Files

- `gym.html` — the entire app (inline CSS + JS)
- `gym-images/` — exercise reference images
